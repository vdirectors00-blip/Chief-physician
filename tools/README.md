# tools — 서비스 상세 페이지 생성기

`services/` 아래 6개 HTML 은 **손으로 고치지 마세요.** 아래 스크립트가 찍어냅니다.
직접 고치면 다음에 다시 돌릴 때 그대로 덮어써집니다.

## 파일

| 파일 | 역할 |
|---|---|
| `gen_pages.py` | 6개 서비스 상세 페이지의 본문(제목, 필요 조건, 하는 일, 판단 기준, FAQ)과 아이콘 |
| `formtpl.py` | 랜딩과 상세가 함께 쓰는 신청 폼, GA4 · 알림 스니펫 |

## 쓰는 법

```bash
cd tools
python gen_pages.py
```

파이썬 3 만 있으면 됩니다. 외부 라이브러리 필요 없습니다.

## 어디를 고치나

- **상세페이지 문구** → `gen_pages.py` 의 `PAGES` 목록
- **아이콘** → `gen_pages.py` 의 `ICONS`
- **하단 안내 문구** → `gen_pages.py` 의 `NOTE`
- **폼 항목 · 상담분야 · 완료 문구** → `formtpl.py`
- **GA4 측정 ID, 알림 중계 주소** → `formtpl.py` 의 `GA` 안 (랜딩 `index.html` 은 따로 고쳐야 함)

## 주의

`index.html` 은 이 스크립트가 만들지 않습니다. 직접 편집합니다.
따라서 **폼을 고칠 때는 `formtpl.py` 를 고쳐 상세 6개를 다시 찍고,
`index.html` 의 폼도 같은 내용으로 맞춰야 합니다.** (현재 폼은 7군데에 있습니다)
